LuanTech | Landing page de vendas

Página de vendas estática da LuanTech: cursos online de programação, um e-book para montar o primeiro PC e produtos físicos de hardware. Feita só com HTML, CSS e JavaScript, sem build e sem dependências. A página não coleta dados dos visitantes e não faz pedidos a serviços de terceiros: as fontes ficam na própria pasta.

A venda e a inscrição são finalizadas fora da página, pelo WhatsApp. Cada botão abre a conversa com uma mensagem já pronta.
